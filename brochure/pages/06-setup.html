Evalezy Set up

Once per paper

Set up once. Every copy gets the same scheme.

Evalezy needs two things before the first copy: the questions, and a marking scheme for each one. Both start from the paper you already printed.

1Question paper import

Upload the paper you already printed.

No typing 38 questions into a form. Upload the question paper as a PDF and Evalezy reads it into questions with their marks and sections.

  • Question text and maximum marks
  • Sections, in paper order
  • Printed numbers kept, so Q21 stays “Q21” on the checked copy
  • Edit any question or mark before you check

2Marking scheme

One scheme per question. The same for every student.

Criteria that add up to the question’s marks. Accept the AI draft, edit it, or write your own.

  • Criteria rescaled to add up exactly to the marks
  • 1 criterion if objective, 3–5 if subjective
  • Model answer is a guide, not set wording
  • Made once, even if two copies start together

Copy 1 and copy 200 are judged the same way.

Over 200 copies, a person’s standard can drift. Evalezy fixes the scheme first and uses it for every copy.

Copy 1

Named weather elements, not climate factors

0.5/3

Copy 87

Three factors, explained, no example

2.5/3

Copy 200

Factors, effects and an example

3/3
