Evalezy API

For developers

Answer sheet evaluation, as an API.

Send a handwritten answer sheet by file or URL. Get back marks per question, feedback, the student’s answer as read and the red-pen checked PDF. Same engine as the Evalezy dashboard.

₹1 / $0.01

per page, excl. GST: the same price as the dashboard. Billed only when an evaluation completes.

  1. 1

    Create an assessment

    Questions with marks, or a question paper URL to be read into questions.

    POST /assessments
  2. 2

    Set the criteria

    Criteria and model answers per question, rescaled to sum to its marks, or a draft to edit.

    PUT …/criteria
  3. 3

    Send an answer sheet

    A PDF by URL, or a file id from /files. Add your own student id.

    POST /evaluations
  4. 4

    Get the result

    Poll, or wait for the webhook: total, marks and feedback per question, and the checked PDF.

    GET /evaluations/{id}

Request access

API access is enabled per account. Request it at evalezy.com/demo with your use case and monthly volume.

Endpoints base https://api.evalezy.com/v1

POST/assessmentsCreate from questions with marks, or a question paper URL
GET/assessments/{id}Questions, marks and current criteria
PUT/assessments/{id}/criteriaCriteria and model answers per question
POST/assessments/{id}/criteria/generateDraft criteria to review and edit
POST/filesUpload an answer sheet PDF; returns a file id
POST/evaluationsCheck one sheet, by file id or URL, with an optional webhook
GET/evaluations/{id}Status, progress, then marks, feedback and the checked PDF
POST/evaluations/{id}/cancelStop a running evaluation; not billed
